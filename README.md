# Camera App with Free Fire Face Masks

A real-time camera application featuring Free Fire-themed face masks and filters.

## Features

- 📷 Real-time camera capture
- 🎭 Free Fire themed face masks
- ✨ Multiple mask designs
- 🎨 Live preview with face detection
- 📸 Photo capture with applied masks
- 🎥 Video recording capabilities

## Face Masks Available

1. **Skull Mask** - Classic skull design inspired by Free Fire character
2. **Neon Mask** - Futuristic neon glow effect
3. **Combat Mask** - Military tactical style
4. **Diamond Mask** - Shimmering precious stone effect
5. **Fire Mask** - Flaming effects mask
6. **Shadow Mask** - Dark ninja-style mask

## Installation

```bash
npm install
```

## Usage

```bash
npm start
```

## Technologies

- React
- WebGL/Canvas API
- Face-api.js for face detection
- Three.js for 3D mask rendering
